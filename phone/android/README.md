# CamLink — Android-приложение-мост для CheatSheet2

Цепочка работы:

1. Снимаете фото на устройстве (ESP32-S3-CAM).
2. Открываете CamLink на телефоне — приложение подключится к SoftAP
   устройства `CSCAM` (системный диалог «Подключиться» — один тап).
   **Интернет телефона не задействуется** — подключение локальное
   (`WifiNetworkSpecifier`), мобильный интернет остаётся дефолтным.
3. Жмёте «Спросить ИИ о последнем фото»:
   `GET /api/photo` → сжатие ≤1568px → API ИИ (Gemini/OpenAI, по ключу)
   → `POST /api/answer`.
4. Ответ текстом автоматически появляется на экране устройства
   (экран «ИИ» открывается сам).

## Сборка

Нужен Android Studio (или `./gradlew assembleDebug` при наличии SDK):

1. Android Studio → *Open* → папку `phone/android`.
2. Дождаться Gradle sync (скачает Gradle 8.7 + AGP 8.5; wrapper-jar
   Android Studio предложит создать — согласиться).
3. Run ▶ на телефоне (Android 10+, minSdk 29).

## Настройки (кнопка «⚙ Настройки»)

| Поле | Зачем |
|------|-------|
| Провайдер ИИ | Google Gemini Flash или OpenAI GPT-4o-mini |
| API-ключ | Ключ выбранного провайдера (нужен баланс/бесплатный лимит) |
| Промпт | Что спрашивать ИИ (по умолчанию — «ответь кратко на вопрос с фото») |
| SSID/пароль | Сеть устройства (`CSCAM` / `cscam1234` по умолчанию) |

## HTTP API устройства (для отладки)

- `GET  http://192.168.4.1/api/state` — `{"state":…,"id":…,"name":…,"seq":…}`
- `GET  http://192.168.4.1/api/photo` — последнее фото (JPEG)
- `POST http://192.168.4.1/api/answer` — заголовок `X-Id`, тело — текст ответа
- `GET  http://192.168.4.1/` — страница с фото/ответом (отладка из браузера)

Внешних зависимостей нет — только системные Android API.
