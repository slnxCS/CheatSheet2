# CheatSheet2 — Схема подключения

## Плата: ESP32-S3-N16R8 CAM (OV5640)

---

### Занятые GPIO (НЕЛЬЗЯ использовать)

```
┌────────────────────────────────────────────────────────┐
│ GPIO 0      — BOOT (strapping)                        │
│ GPIO 4-13   — Камера DVP (фирксована на плате)       │
│ GPIO 15-18  — Камера DVP                             │
│ GPIO 19-20  — USB D-/D+                               │
│ GPIO 26-32  — Flash SPI (internal)                    │
│ GPIO 33-37  — Octal PSRAM (8MB OPI)                  │
│ GPIO 38-40  — SD-карта (распаяна на плате)           │
│ GPIO 48     — WS2812 RGB LED (на некоторых платах)   │
└────────────────────────────────────────────────────────┘
```

### TFT 2.0" ST7789 240x320 (SPI)

```
┌─────────────────┐          ┌──────────────────────────┐
│   ST7789 TFT    │          │  ESP32-S3-N16R8 CAM      │
│                 │          │                          │
│  VCC  ──────────┼──────────┼── 3V3                    │
│  GND  ──────────┼──────────┼── GND                    │
│  MOSI ──────────┼──────────┼── GPIO 42                │
│  SCLK──────────┼──────────┼── GPIO 41                │
│  CS   ──────────┼──────────┼── GPIO 47                │
│  DC   ──────────┼──────────┼── GPIO 46                │
│  RST  ──────────┼── 3.3V   │  ( pull-up 10k к 3.3V ) │
│  BL   ──────────┼──────────┼── GPIO 45                │
│  MISO ──────────┼── (NC)   │  (не подключается)       │
└─────────────────┘          └──────────────────────────┘

ВАЖНО: RST не подключается к ESP32!
Подключите RST к 3.3V через подтягивающий резистор 10kОм.
Это освобождает GPIO для кнопок.
```

**Частота SPI**: 80 МГц
**Примечание**: MISO не используется — ST7789 только на запись

---

### Кнопки (5 шт, крестовина + OK)

```
┌───────────────┐          ┌──────────────────────────┐
│   Кнопка      │          │  ESP32-S3-N16R8 CAM      │
│               │          │                          │
│  UP    ───────┼──────────┼── GPIO 1  (P2 pin 4)    │
│  DOWN  ───────┼──────────┼── GPIO 2  (P2 pin 5)    │
│  LEFT  ───────┼──────────┼── GPIO 14 (P1 pin 19)   │
│  RIGHT ───────┼──────────┼── GPIO 3  (P1 pin 12)   │
│  OK    ───────┼──────────┼── GPIO 21 (P2 pin 18)   │
│               │          │                          │
│  Все GND ─────┼──────────┼── GND                    │
└───────────────┘          └──────────────────────────┘

Схема подключения одной кнопки:

    3.3V
     │
     ├── [Внутренний pull-up в ESP32]
     │
  GPIO ──────────────────┐
                         │
                    [КНОПКА]
                         │
                        GND

    Нажато:   GPIO = LOW  (0V)
    Отпущено: GPIO = HIGH (3.3V)
```

**Debounce**: 50 мс (программный)
**Long press**: 800 мс

### Камера OV5640 (DVP, припаяна к плате)

```
Камера OV5640 подключена через FPC коннектор на плате.
Все пины фиксированы, менять НЕЛЬЗЯ.

┌──────────────────┬─────────────────────────────┐
│ Сигнал OV5640    │ GPIO ESP32-S3               │
├──────────────────┼─────────────────────────────┤
│ XCLK             │ GPIO 15                     │
│ SIOD (SDA)       │ GPIO 4                      │
│ SIOC (SCL)       │ GPIO 5                      │
│ VSYNC            │ GPIO 6                      │
│ HREF             │ GPIO 7                      │
│ PCLK             │ GPIO 13                     │
│ D0 (Y2)          │ GPIO 11                     │
│ D1 (Y3)          │ GPIO 9                      │
│ D2 (Y4)          │ GPIO 8                      │
│ D3 (Y5)          │ GPIO 10                     │
│ D4 (Y6)          │ GPIO 12                     │
│ D5 (Y7)          │ GPIO 18                     │
│ D6 (Y8)          │ GPIO 17                     │
│ D7 (Y9)          │ GPIO 16                     │
│ PWDN             │ не подключён (-1)           │
│ RESET            │ не подключён (-1)           │
└──────────────────┴─────────────────────────────┘
```

### SD-карта (распаяна на плате)

```
SD-карта использует SPI шину и занимает 3 GPIO.
Пины подписаны на плате с символом "~" (meaning SD).

┌──────────────────┬─────────────────────────────┐
│ Сигнал SD        │ GPIO ESP32-S3               │
├──────────────────┼─────────────────────────────┤
│ CS               │ GPIO 38                     │
│ CLK              │ GPIO 39                     │
│ MOSI             │ GPIO 40                     │
└──────────────────┴─────────────────────────────┘

Эти GPIO заняты и НЕЛЬЗЯ использовать для других целей.
```

### Питание

```
┌────────────────────────────────────────────────────────┐
│ USB Type-C 1  — UART дебаг (CH340/CP2102)             │
│ USB Type-C 2  — USB OTG (GPIO 19/20)                  │
│ 5V пин        — Вход питания от батареи/адаптера      │
│ 3V3 пин       — Выход стабилизатора 3.3V (макс 500мА)│
│                Вся логика работает на 3.3V             │
└────────────────────────────────────────────────────────┘

Потребление:
- Простой: ~100 мА
- Камера стриминг: ~350 мА
- Максимум (WiFi + камера + дисплей): ~500 мА
```
