# CheatSheet2

Портативное устройство на **ESP32-S3-N16R8 CAM** с цветным дисплеем, камерой и 5 кнопками управления. Изначально задумано как «электронная шпаргалка» — для быстрого доступа к заметкам и фото документов.

## Возможности

- 📷 **Камера** — live-превью, **автофокус (CDAF)** перед каждым снимком, снимки JPEG с поворотом -90° и зеркалированием (сенсор физически развёрнут на плате). Сохранённый файл оптимизирован под распознавание текста: сенсор q4 + макс. резкость/контраст, перекодирование в Q_BEST 4:4:4
- 🗂 **Проводник** — просмотр файлов на Flash (LittleFS) и SD-карте, открытие текстовых файлов и JPEG
- ⚙️ **Настройки** — яркость, язык (RU/EN), выбор накопителя
- 🔁 **Повтор нажатий** — удержание кнопок навигации для плавной прокрутки
- 💾 **Сохранение фото** — на Flash или SD-карту с меткой времени
- 📡 **Связь с телефоном** — SoftAP «CSCAM» + HTTP-мост: фото уходит на телефон,
  ответ ИИ текстом возвращается и показывается на экране устройства (экран «ИИ»).
  Android-приложение-мост — `phone/android/` (Gemini/OpenAI vision)
- 🎮 **Игры** — Snake, 2048, Tetris, Flappy (canvas-рендеринг, рекорды)

## Железо

| Компонент | Модель |
|-----------|--------|
| MCU | ESP32-S3-N16R8 (16MB Flash, 8MB PSRAM) |
| Камера | OV5640 (DVP, припаяна) |
| Дисплей | ST7789 2.0" 240×320 (SPI, landscape) |
| Управление | 5 кнопок (крестовина + OK) |
| SD-карта | MicroSD (распаяна, GPIO 38-40) |

### Распиновка

```
TFT ST7789:          Кнопки:
  MOSI → GPIO 42       UP    → GPIO 1
  SCLK → GPIO 41       DOWN  → GPIO 2
  CS   → GPIO 47       LEFT  → GPIO 14
  DC   → GPIO 46       RIGHT → GPIO 3
  BL   → GPIO 45       OK    → GPIO 21
```

Подробная схема подключения: [HARDWARE.md](HARDWARE.md)

## Сборка

### Требования

- [PlatformIO CLI](https://platformio.org/install/cli) или плагин для VS Code
- ESP32-S3 плата подключена по USB (UART)

### Прошивка

```bash
# Полная прошивка (firmware + partition table)
pio run -t upload

# Монитор SERIAL для отладки
pio device monitor
```

> ⚠️ При первом запуске LittleFS автоматически форматируется.

### Прошивка только firmware (без partitions)

```bash
pio run -t upload
```

## Технические детали

### Камера

- Разрешение снимка: UXGA (1600×1200), сенсор q4 + резкость/контраст на максимуме
- Превью: QUARTER scale (400×300 декодируется), canvas во весь экран 320×240;
  декод идёт в отдельной FreeRTOS-задаче на core 0 — интерфейс не тормозит
- Режимы превью: «во всю ширину» (по умолчанию — кроп по центру, текст читается крупно)
  и «весь кадр» (поля по бокам, видно сцену целиком) — переключение длинным нажатием
  любой кнопки навигации; сам файл всегда содержит полный кадр
- Автофокус (CDAF): контрастный перебор VCM-мотора (грубый + точная подстройка,
  метрика — сумма градиентов яркости), запускается при открытии камеры и перед
  каждым снимком (~2 с); кадр для метрики берётся гарантированно свежий
  (`camera_capture_after` — по timestamp кадра). Ручной фокус LEFT/RIGHT — запасной
- Снимок: декод в RGB565 с транспонированием + перекодирование JPEGENC Q_BEST 4:4:4
- JPEGDEC (bitbank2/JPEGDEC) + JPEGENC, запись через callbacks прямо в File

### Связь с телефоном (мост к ИИ)

Цепочка: **снимок → телефон → API ИИ → ответ текстом на экране устройства**.
Никакого общего интернета: устройство поднимает собственный SoftAP, телефон
подключается к нему как к локальной сети (Android: `WifiNetworkSpecifier`) и
остаётся на мобильном интернете для запроса к ИИ.

- SoftAP `CSCAM` (WPA2, пароль `cscam1234`, IP `192.168.4.1`) — сервис
  `wifi_service`, переключатель в «Настройках», иконка в статус-баре
- HTTP-сервер (`ai_link`, отдельная FreeRTOS-задача, порт 80):
  - `GET /api/state` — JSON: состояние очереди, id фото, длина ответа
  - `GET /api/photo` — отдаёт последнее снятое фото (помечается «взято»)
  - `POST /api/answer` — заголовок `X-Id` + текст в теле → ответ на устройство
  - `GET /` — отладочная страница (посмотреть фото/ответ из браузера)
- После снимка фото автоматически встаёт в очередь; при получении ответа
  экран «ИИ» открывается сам (текст с переносом и прокруткой UP/DOWN)
- Android-приложение-мост: `phone/android/` (забрать фото → resize ≤1568px →
  OpenAI/Gemini vision → POST ответа)

### Дисплей

- LVGL 9.x с кастомными шрифтами (кириллица 10-28px)

| app0 | 2.5 MB | Прошивка |

### Кнопки

- Дебаунс: 20 мс
- Long press: 800 мс (выход из приложений)
- Repeat-fire: 300 мс задержка, 80 мс интервал (навигационные кнопки)
